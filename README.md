# Focus Flow

Focus Flow — небольшой фокус-таймер с задачами, статистикой и сохранением состояния в браузере. Проект сделан как аккуратный GitHub-пет-проект: его легко открыть, показать в портфолио и развивать дальше.

![Focus Flow preview](./assets/preview.svg)

## Возможности

- таймер для фокус-сессии, короткого и длинного перерыва;
- список задач на день;
- счетчик выполненных задач;
- статистика фокус-сессий и минут;
- светлая и темная тема;
- сохранение данных через `localStorage`;
- адаптивная верстка для телефона и десктопа.

## Запуск

Откройте `index.html` в браузере.

Также можно запустить локальный сервер:

```bash
python -m http.server 8080
```

После этого проект будет доступен по адресу:

```text
http://localhost:8080
```
