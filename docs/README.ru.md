# Focus Flow: русская справка

Focus Flow — небольшой фокус-таймер с задачами, статистикой и сохранением состояния в браузере.

Основной проект, интерфейс и README сделаны на английском, чтобы репозиторий выглядел универсально для GitHub и портфолио. Этот файл оставлен как дополнительная русская справка.

## Что есть в проекте

- таймер для фокус-сессии, короткого и длинного перерыва;
- список задач на день;
- счетчик выполненных задач;
- статистика фокус-сессий и минут;
- светлая и темная тема;
- сохранение данных через `localStorage`;
- адаптивная верстка.

## Как запустить

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8080
```

После этого откройте:

```text
http://localhost:8080
```
